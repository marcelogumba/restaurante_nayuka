# Nayuka — Sabores da Alma

Cardápio digital em Next.js com App Router, TypeScript e Lucide React.

## Instalação

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Estrutura

- `src/app` — páginas e rotas
- `src/components` — componentes reutilizáveis
- `src/data` — categorias e 106 produtos
- `src/lib` — utilitários
- `public/images` — logo e imagens
